## 🌟 Overview
**GrowthPath** is a comprehensive, production-grade SaaS career platform designed to help computer science students bridge the gap between academic learning and industry hiring.

It combines:
- 📊 **ATS Resume Analyzer Engine**: Instant 100-point scoring, keyword matching, and formatting recommendations.
- 🏢 **Target Company Preparation Suite**: Specialized roadmaps for 10 top tech companies including Google, Accenture, TCS, Infosys, Wipro, Amazon, Microsoft, Deloitte, JPMorgan, and Flipkart.
- 🗺️ **My 7-Step Career Roadmap**: Interactive tracking from Fundamentals ➔ Master DSA ➔ Build Projects ➔ ATS Resume ➔ Practice Interviews ➔ Apply Jobs ➔ Track Applications.
- 🧪 **Project Lab & Automated AI Quality Scorecard**: 4-field project submission form evaluating Code Quality, UI/UX Polish, and Documentation.
- 👤 **Professional User Profile System**: Dark neon SaaS glassmorphism UI with database persistence.

---

## 🛠️ Tech Stack & Architecture
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Backend**: Node.js, Express.js REST API Server.
- **Database**: SQLite (`growthpath.sqlite`) with tables for Users, Profiles, Resumes, Project Submissions, and Job Applications.
- **Design System**: Deep navy `#080B14`, vibrant blue/purple accents, WCAG 2.1 AA accessible contrast.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run Commands
```bash
# 1. Clone repository
git clone https://github.com/shivamsingh018/growthpath.git
cd growthpath

# 2. Install dependencies
npm install

# 3. Start Backend Express API (Port 5001)
node server/index.js

# 4. Start Frontend Vite Dev Server (Port 3000)
npm run dev
```
